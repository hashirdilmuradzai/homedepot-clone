# Home Depot Website Clone

A frontend website clone inspired by the official **The Home Depot** website, developed using **HTML5, CSS3, Bootstrap, and JavaScript libraries**.

This project was created as a frontend development practice project to recreate a professional e-commerce and home improvement website interface, including product browsing, navigation, shopping features, order summary, and receipt layouts.

---

This project is inspired by the official Home Depot website:

## 📖 About The Project

The **Home Depot Website Clone** is a frontend implementation inspired by the design and layout of a large-scale home improvement and e-commerce platform.

The project focuses on recreating a professional shopping interface using traditional frontend technologies.

It includes a main shopping page along with dedicated **Order Summary** and **Order Receipt** pages.

The project was developed without using modern frontend frameworks such as React, Vue, or Angular.

## 💻 Installation & Setup

No additional build tools or package installation are required.

### 1. Download the Repository

Download or clone this repository to your local machine.

### 2. Open the Project

Open the project folder in **Visual Studio Code** or any preferred code editor.

### 3. Run the Website

Open the following file in your browser:

```text
index.html
```

You can also use the **Live Server** extension in Visual Studio Code for development.
